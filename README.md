# La noche que eligió tu nombre

Un libro romántico interactivo para Emily sobre una conexión que nació de forma natural en apenas dos semanas, con páginas animadas, poemas originales y un pequeño homenaje a *Noches blancas* de Fiódor Dostoievski.

Las páginas pueden recorrerse con los botones, las flechas del teclado o un gesto horizontal en dispositivos táctiles.
