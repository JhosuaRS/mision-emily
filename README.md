# La noche que eligió tu nombre

Un libro romántico interactivo para Emily sobre una conexión que nació de forma natural en apenas dos semanas. Alterna poemas originales y mitología griega con citas breves de Bécquer, Jane Austen, Emily Brontë, Dostoievski y Quevedo.

Las páginas pueden recorrerse con los botones, las flechas del teclado o un gesto horizontal en dispositivos táctiles.
